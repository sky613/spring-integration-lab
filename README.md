# enterprise-integration-hub

Spring Boot 기반 Enterprise Integration Hub 프로젝트입니다.

## 빠른 시작

```bash
./gradlew test       # 테스트
./gradlew bootRun    # 실행 (http://localhost:8080)
docker compose up -d --build   # Docker 실행
```
